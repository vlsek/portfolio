# Portfolio

Статическая визитка. Чистые HTML/CSS/JS, без сборки, без бэкенда.

- `index.html` — контент визитки (текст, ссылки, проекты)
- `portfolio.css` — стили
- `i18n.js` — переключатель языка (RU/EN)

## Хостинг

Cloudflare Pages, билд — статика из корня репозитория. Автодеплой на пуш в `main`.
